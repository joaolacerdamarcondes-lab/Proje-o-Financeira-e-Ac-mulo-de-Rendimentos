# Proje-o-Financeira-e-Ac-mulo-de-Rendimentos
Este projeto consiste em uma página interativa criada para simular a evolução patrimonial de reservas anuais ao longo de 8 anos, considerando reajustes salariais e uma taxa de rendimento passivo de **10% ao ano** (juros compostos).  Projeto desenvolvido para as disciplinas de **Matemática Aplicada** e **Tecnologia** no 1º Ano do Ensino Médio.
